# Glitch's Races

A Minecraft Java Edition data pack that adds a vanilla-friendly way to play as different races, along with lore about each one, new gear, and new enchantments. It was inspired by the Origins mod.

## Features

### Races
Choose your race and explore what makes each one unique, including Ender, Fairy, Feilene, Goblin, Elf, Creeper, Bloom, Blaze Spawn, Honey Bee, Kraken, Mole, Orc, Rythmer, Soul Knight, Spider, Werewolf, Warden, Gooby, and Armadillo. Each race has its own abilities, drawbacks.

### Items
- **Species Essence**: switch your race
- **Mole Drigger**: mine faster and dig in a 3x3 area
- **Orc Hammer**: a heavy weapon that can also be used to defend
- **Flavored Mace**: an edible mace

### Enchantments
- **Flame Cover**: burns anything that touches your armor
- **Light Foot**: jump higher (boots)
- **Thunder Strike**: summons lightning on a victim with certain melee weapons
- **Wall Breaker**: breaks blocks in a 3x3 area where you're looking
- **True Vision**: grants night vision when worn on a helmet


## Status
This pack is in early development, and features like new dimensions are still being worked on. It targets the newest Minecraft version and won't be backported to older versions.
